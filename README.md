Практична робота №5

Розв’язання транспортної задачі

Консольна програма мовою C# для розв’язання транспортної задачі.

Можливості

- введення даних вручну;
- завантаження варіанта 12;
- перевірка транспортної задачі на відкриту або закриту форму;
- побудова опорного плану:
  - методом північно-західного кута;
  - методом мінімального елемента;
- пошук оптимального плану методом потенціалів;
- розв’язання транспортної задачі симплекс-методом;
- виведення покрокового протоколу обчислень.

Структура проєкту

- `Program.cs` — головне меню;
- `TransportData.cs` — зберігання даних і перевірка балансу;
- `TransportSolver.cs` — методи північно-західного кута, мінімального елемента та потенціалів;
- `SimplexSolver.cs` — симплекс-метод;
- `Printer.cs` — виведення таблиць;
- `Cell.cs` — допоміжний клас.
